# Support

**Playing Kuluu and stuck?** Ask in [Discord](https://discord.gg/5c8NK46SuD).
That is where setup help, server questions and bug reports from players go,
and where you will hear about new builds.

**Looking for a download?** Prebuilt archives for Windows, macOS and Linux are
on the [Releases](https://github.com/jondwillis/kuluu-ffxi/releases) page. The
README's [Playing](README.md#playing) section covers first launch and the
game files.

**Found a bug and want to fix it?** GitHub Issues here are a published
projection of the project's backlog, so a report is most useful as a Discord
message or, if you are contributing, as a pull request. See
[CONTRIBUTING.md](CONTRIBUTING.md).

Kuluu connects to community-run private servers only. For account or server
problems, contact that server's own support.
